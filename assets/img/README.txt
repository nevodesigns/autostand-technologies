Drop the AutoStand logo in this folder.

  logo.svg      mark used in the header and footer (26px / 24px displayed)
  favicon.svg   browser tab icon, needs its own dark background

Both are placeholders. Replacing logo.svg alone updates the header and footer.
If the logo is a raster file (PNG/JPG), save it here and change the two
<img src="assets/img/logo.svg"> references in index.html to the new filename.

The brand colour lives in one place: --accent in assets/css/styles.css.
